# Roadmaps

Two independent opinions, both written on 28 September 2026, about the order of work toward real-money poker under a Malta licence. They are not a specification and not a decision.

Read [the progress index](../progress/README.md) and the code before following either one. If you disagree, say why, and do the better-supported thing within the user's instructions.

| Document | What it argues |
| --- | --- |
| [Sol, 28 September 2026](2026-09-28-sol.md) | A trustworthy play-chip release first, then frozen rules, then a separate money system, then player protection, then regulator evidence. |
| [Codex, 28 September 2026](2026-09-28-codex.md) | Repair the reproduced defects and make the operating decisions concrete, then build the financial and eligibility systems. Includes a finding-to-work map for F01–F22. |

A later opinion belongs in this folder as a dated file. Do not add a model-named markdown file to the repository root, and do not present the opinion as a project decision.
